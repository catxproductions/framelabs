Interpretation: This is a qualitative, reduced-order teaching model. Material capacities, impact resistance, kinetic-energy transfer, impulse, fracture thresholds, deformation and shockwave propagation use illustrative units, not calibrated real-world properties or engineering calculations. The model demonstrates conceptual behavior but does not validate actual building safety.
Tips: Build continuous columns from the foundation, connect them with beams, add slabs, then select Validate. Apply loads to individual bays and use the heatmap to inspect weak points. Demolish removes a member immediately; failures during simulation create movable debris. Save JSON exports the design and member damage state (not a live replay). Keyboard shortcuts: B build · D demolish · L apply load · P push · V validate · Space simulate/pause.
